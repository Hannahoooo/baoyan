☁️ 多设备同步 未开启

开启后，手机和电脑会自动同步同一份数据。同步用 GitHub 免费服务，不需要服务器。
怎么拿到 Token？（点开看 3 步）
1. 注册/登录 GitHub → 打开 github.com/settings/tokens
2. 点 Generate new token (classic) → Note 随便写（如 baoyan）→ 有效期选 90 天或不失效
3. 勾选 gist 这一个权限即可 → 生成 → 复制那串 ghp_ 开头的字符，粘贴到上面
两台设备粘贴同一个 Token，会自动找到同一份数据，不用再配置别的。

📌 怎么放到手机桌面

手机浏览器打开本页 → 点“分享 / 菜单” → 选择“添加到主屏幕”。 之后就像 App 一样一点就开，没有网络也能用。
